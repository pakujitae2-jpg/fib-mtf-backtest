**§0.2 결정 구조에서 선택한 가지: `B4 FAIL → 개념 폐기. 피보나치 진입 계열 종료`.**
근거: (1) 손절이라는 실행 장치를 떼어내고, 전략에 유리하도록 설계한 순방향 검정에서도 3일~30일 지평의 초과수익이 전부 음수다. (2) 손절폭을 6종으로 바꿔도 같은 손절폭의 무작위 진입을 이기지 못한다(B5). (3) F′-1 의 "진입 기여" 는 분해하면 R 유효 구간의 조건부성과 진입가 수준 효과로 설명되고, 터치 이후의 공정한 무작위 진입도 청산 기계만으로 PF 1.7 을 낸다. 진입이 실제 PF 를 끌어올린 것은 사실이나 그것은 **"더 싸게 산다"** 의 효과이지 **"오를 때를 안다"** 의 효과가 아니며, B4 는 그 진입가에서의 이후 방향이 무작위보다 나쁘다고 말한다. (4) 무엇보다 F′-0: 시스템 전체(전략 + 청산 기계) 가 BH·BH-x 에 크게 못 미치고, 무작위 진입 + 청산 기계는 노출 매칭 B&H 도 못 이긴다. 5차 FAIL 을 뒤집을 근거는 어디에도 없다.

동시에 성립하는 다른 가지: `F′-0 벤치마크 미달 → 전략 전체 재검토`. F′-1 의 `≥95 → 지표 재설계` 가지는 위 분해에 따라 채택하지 않는다(§5.4 에 상세).

## 3. B4 — 손절 없는 순방향 수익률

### 3.1 표본 · 측정 · 편향 방향
- 전략: 5차 shadow 후보 전수 (V2 101 / V3 93, 재생성 후 n assert). baseline: 5차 B-R1 과 동일 추출(±5일 창, 후보당 20개, seed 20260829), 5분봉 시가 진입.
- `r_H = ln(close(entry_time + H) / entry_px)`, H ∈ {6h, 24h, 3d, 7d, 14d, 30d}. 손절·익절·청산·비용 없음. 봉이 없으면 직전 봉 종가(gap_filled 태깅), 데이터 종료 이후는 censored 로 제외.
- 주 지표 = 후보당 짝지은 창 내 초과수익 `excess_H(i) = r_H(전략 i) − mean_j r_H(무작위 j of i)`. 연도/월 블록 부트스트랩 5,000회, Holm–Bonferroni 로 6개 지평 보정.
- **편향 방향(§2.5, 원문 그대로):** 이 검정은 전략에 유리하게 설계되어 있다. 전략은 눌림목 지정가 매수라 창 안에서 국지적으로 낮은 가격에 들어가고, baseline 은 창 안 임의 시점의 시가에 들어간다. 평균 회귀가 조금이라도 있으면 전략이 이긴다. 그럼에도 초과수익이 0 이하라면 결론은 강하다.

## 6. 종합 판정과 다음 단계

§0.2 결정 구조 중 **`B4 FAIL → 개념 폐기. 피보나치 진입 계열 종료`** 를 선택한다.

- B4: 손절 없이도 진입 시점에 방향 정보가 없다(3~30일 초과수익 전부 음수, 유리한 설계에서도). 이것이 결정 구조의 첫 분기이고, 여기서 갈린 뒤의 B5·F′ 결과는 이를 뒤집지 못한다.
- B5: 손절폭은 원인이 아니다. 6종 전부 FAIL, 넓힐수록 gap 은 0 이하로 수렴.
- F′-1: 형식상 "진입 기여 있음" 이지만 분해 결과 예측력이 아닌 실행 가격·조건부성 효과. F′-2 는 "약한 기여". 청산 기계 단독으로는 BH-EM 도 못 이긴다.
- F′-0: 전략 전체가 BH·BH-x 에 크게 미달(CAGR 8.6% vs 49.5% / 27.9%). 이 가지(`전략 전체 재검토`) 도 동시에 성립한다.

다음 단계:
1. **피보나치 진입 계열(D ZigZag ARM → 4H R 레드라인) 종료.** Test C~K, 등급화·빈도 확장·손절 재설계·R_ENTRY_FIB 최적화 전부 중단.
2. "청산 전략" 으로의 재정의도 이번 데이터로는 지지되지 않는다(무작위 진입 + 청산 기계 < BH-EM). 청산 기계를 살리려면 먼저 F′-2 형태의 검정에서 BH-EM 을 유의하게 이겨야 한다.
3. 재설계를 한다면 출발점은 "BTC 롱 노출을 언제 줄일 것인가"(BH 대비 MDD 76% 를 줄이면서 CAGR 을 덜 잃는 장치) 이며, 그 가설도 같은 절차(shadow/baseline → 벤치마크) 를 먼저 통과해야 한다.
4. 봇(`fib_bot.py`) 의 forward test 는 보류 상태 유지.

## 7. 한계 · 미검증

- 표본: 전략 shadow 101/93건, 실제 거래 82/79건. B4·B5 의 신뢰구간은 넓고 연도별 셀은 대부분 n < 20 이다. 결론은 "우위 확인 실패 + 방향 정보 부재의 일관된 증거" 이며, 우위의 부재를 정밀 추정한 것은 아니다.
- B4 는 H 시점 종가 하나만 보는 점 추정이다(중간 경로 무시가 목적). 6개 지평의 다중비교는 Holm 으로 보정했고 보정 후 유의한 것은 음의 방향뿐이다.
- B5 baseline 재추출(seed 20260830) 로 S1 gap 이 −3.9(V2)/+0.3(V3) 로 움직인다 — baseline 표본 오차 ±1%p 를 gap 해석의 해상도로 봐야 한다.
- F′-1 의 무작위 진입 시가 ≤ 손절인 추출은 재추출/skip 했다(V2 600건/200회). 재추출은 유효 진입 쪽으로 약간 편향되나 실제 전략에 불리한 방향은 아니다.
- F′-1 의 조건부성은 지시서 설계("같은 R 의 유효 구간") 자체의 성질이다. 이를 지적하려고 F′-1b 와 터치 전/후 분해를 추가했고, 이는 지시서 외 보조 진단이다. F′-1 본 검정의 설계·시드·결과는 그대로 보고했다.
- F′-2 의 dexit/V 치환은 §4.4 표대로만 했다. 치환 때문에 원본 청산 기계와 동일하지 않으며 해석 등급이 낮다.
- BH-x 는 일 리밸런스 근사(리밸런스 비용 미반영). BH 계열 Sharpe/Sortino 는 일수익률 기준이라 거래 단위 전략 값과 직접 비교할 수 없다(표에 명시).
- 비용: B4·B5 는 비용·펀딩 미반영(지시서), F′ 는 반영. F′-1 의 무작위 진입은 taker 가정이 기본이며 maker 병기 결과도 결론이 같다.
- `fib_bot.py` 는 여전히 레거시 `fib_mtf` 를 import 한다. 이번 범위 밖이며, forward test 전 `fib_engine_c` 전환이 필요하다 — 다만 본 판정으로 forward test 자체가 보류된다.
- V1 HOLD 유지.
