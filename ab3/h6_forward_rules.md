# H6 — 순방향 운용 기준 (거래 시작 전 확정)

- 대상: V2 롱 신호(교정 엔진), 등급별 차등 위험 배분 (A 0.75% / B·C 0.50%, 동시 오픈 위험 ≤ 1.5%), cap_lev 10. 생존 조건 k=0 → 등급 없음 → 전부 B, 균일 0.5% 운용

## 8.1 기대 기준선
- **건당 기대 R = -0.216R** (H5 교정 엔진 롱 전용 WF 2022~26, 동점 처리 두 값 -0.216 / -0.216 중 낮은 쪽; PF 0.56). 운용 문서의 PF 4.32 / +2.28R 은 삭제한다 (2023~26 실제 거래의 in-sample 값).
- 참고: A1 DEV(2019~22) 실현 mean R +0.257 (sd 2.95), 전체 82건 mean R +0.875.
- "0 엣지" 누적 R 분포 (DEV R_REAL 분포를 평균 0 으로 이동, 복원추출 5000회, seed 20261001):

| 거래 수 | p5 | p50 | p95 |
|---|---:|---:|---:|
| 15건 | -17.1R | -1.1R | +19.9R |
| 25건 | -22.1R | -1.0R | +24.9R |
| 50건 | -32.0R | -1.0R | +34.5R |

## 8.2 중단선 (둘 중 먼저 오는 것)
1. **낙폭**: 차등 배분 기준 실현 낙폭이 **17.9%** (H4 순서 MC 99백분위) 를 초과하면 즉시 중단·재검토. (참고: MC p50 7.5%, p95 13.9%; 과거 실제 차등 배분 전체 구간 실현 MDD 7.7%)
2. **누적 R**: 순방향 25건 누적 R 이 **-22.1R** (0 엣지 분포 5백분위) 미만이면 중단·재검토.

- 15건은 검증이 아니라 재앙 감지용이다 (0 엣지에서도 15건 누적 R 의 90% 구간은 -17.1 ~ +19.9R 로 넓다).
- 엣지 확인에 필요한 건수: WF 기준선이 -0.216R 로 0 이하라 **확인할 엣지가 없다.** 참고로 DEV 실현 평균 +0.257R 이 진짜라면 t=2 확인에 약 527건, 전체 82건 평균 +0.875R 이 진짜라면 약 46건이 필요하다 (sd 2.95, 독립 가정). 즉 50건 이전에는 어떤 결과도 엣지의 확인이 아니다.

## 8.3 승격 조건
- 순방향 15건 후 실현 낙폭이 **7.5%** (MC 50백분위) 이내이고 누적 R > 0 이면 건당 상한을 1.0% 로 승격 가능. 그 전까지 1.0% 초과 금지.
- 승격 후에도 동시 오픈 위험 합 1.5% 상한과 §8.2 중단선은 유지한다.
