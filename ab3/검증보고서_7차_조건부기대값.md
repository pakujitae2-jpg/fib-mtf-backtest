## 9. H6 — 순방향 운용 기준 (`ab3/h6_forward_rules.md`, 숫자로 확정)

- **기대 기준선**: 건당 **−0.216R** (H5). 운용 문서의 PF 4.32 / +2.28R 삭제. 참고: A1 DEV 실현 평균 +0.257R (sd 2.95), 전체 +0.875R.
- **0 엣지 누적 R 분포** (DEV R_REAL 을 평균 0 으로 이동, 5,000회, seed 20261001): 15건 −17.1 / −1.1 / +19.9R, 25건 **−22.1** / −1.0 / +24.9R, 50건 −32.0 / −1.0 / +34.5R (p5 / p50 / p95).
- **중단선** (먼저 오는 것): ① 균일 0.5% 배분 기준 실현 낙폭 > **17.9%** (순서 MC p99) → 즉시 중단·재검토. ② 순방향 25건 누적 R < **−22.1R** → 중단·재검토.
- 15건은 재앙 감지용(0 엣지에서도 15건 누적 R 90% 구간이 −17 ~ +20R). 엣지 확인: WF 기준선이 0 이하라 확인할 엣지가 없다. DEV 평균 +0.26R 이 진짜라면 t=2 확인에 약 527건, 전체 평균 +0.88R 이 진짜라면 약 46건이 필요하다(독립 가정). 50건 이전에는 어떤 결과도 엣지의 확인이 아니다.
- **승격**: 순방향 15건 후 실현 낙폭 ≤ **7.5%** (MC p50) 이고 누적 R > 0 이면 건당 상한 1.0%. 그 전까지 1.0% 초과 금지. 승격 후에도 동시 오픈 위험 1.5% 상한과 중단선 유지.

## 10. 한계 · 미검증

- 표본 경고(§0) 그대로다. DEV P-S 66건 → 셀당 22건, TEST 셀은 1~29건. 생존 0 은 "조건이 없다" 의 증명이 아니라 "이 표본으로 사전 기준을 통과하는 조건을 찾지 못했다" 다.
- VOL30 이 문턱 0.9pp 차이로 탈락했다. 사후에 문턱을 낮추면 통과하지만 그것이 정확히 §0.3 이 금지하는 행위다. 새 지시서 버전에서 (a) VOL30 문턱 재등록 또는 (b) RET14 상위(단기 모멘텀) 를 새 조건으로 사전 등록해 검정할 수 있다 — 둘 다 이 데이터로 이미 한 번 본 가설이므로 새 순방향 표본이 필요하다.
- P-R 은 200회 재추출이라 독립 표본이 아니다. 조건 4 는 "실행 200회 중 양수 비율" 로만 썼다.
- WF 는 EXIT=spec 고정, 롱 전용, 그리드 64. 선택 규칙은 2차와 동일하되 학습 n ≥ 15 문턱도 2차 코드를 따랐다. 2022년 결과가 기준선을 지배한다(15건 전패). 이를 빼면 양수지만, 그것은 "나쁜 해를 빼면 좋다" 는 말이라 기준선에 반영하지 않는다.
- 차등 배분 §6.2 는 k=0 이라 균일과 동일해 "차등이 균일보다 낙폭 대비 수익이 나은가" 는 판단 불가.
- 상대 분석의 exit-aware 등급은 `h3_grades.csv` 에 병기만 했다(A급 위험 0.75% 적용 결과는 상대 분석 보고서 참조). 본 등급 체계와 합치지 않는다.
- `fib_bot.py` 는 여전히 레거시 `fib_mtf` 를 import 한다. 운용 전 `fib_engine_c` 전환 필요.
- 비용 모델은 엔진과 동일(maker 진입, taker 청산, slip, 펀딩). 재량 실행(사람 판단) 의 오차는 반영되지 않았다.
